# Clone-Me AI

AI-powered image generation and identity-preserving photo editing system built with ComfyUI and SDXL.

## Features

- Reference-based identity preservation
- FaceID / IPAdapter workflows
- OpenPose-based pose control
- Outfit and background changes
- Full-body image generation
- Multiple experimental identity workflows
- Automated identity optimization experiments

## Requirements

- NVIDIA GPU
- ComfyUI
- SDXL-compatible checkpoint
- Required ComfyUI custom nodes
- Required identity/reference models

## Project Structure

- ComfyUI/ — local ComfyUI installation (not tracked by Git)
- *.json — generation workflows and optimization logs
- *.bat — ComfyUI launch scripts
- .gitignore — excluded models, generated images and local environments

## Important

Large model files and local runtime files are intentionally excluded from this repository.

This repository contains the workflows and configuration used to build and experiment with Clone-Me AI.
